# 구글 플레이 스토어 등록 안내

스도쿠 놀이터를 갤럭시(안드로이드) 앱으로 플레이 스토어에 올리는 방법입니다.
웹사이트를 그대로 앱으로 감싸는 방식이라, 웹사이트를 고치면 앱에도 자동으로 반영됩니다(앱 업데이트 불필요).

## 준비된 것 (이 폴더)
| 파일 | 용도 |
| --- | --- |
| `listing.md` | 스토어에 붙여넣을 앱 이름·설명 문구 |
| `feature-graphic.png` | 스토어 상단 배너 이미지 (1024×500) |
| `screenshots/` | 휴대전화 스크린샷 4장 (1080×1920) |
| `../icons/icon-512.png` | 앱 아이콘 (512×512) |
| 개인정보처리방침 주소 | https://yuna123-tech.github.io/sudoku/privacy.html |

---

## 1단계. 구글 개발자 계정 만들기 (약 30분 + 승인 대기)
1. https://play.google.com/console 에 구글 계정으로 접속합니다.
2. **개인** 계정을 선택하고, 등록비 **25달러(약 3만 5천 원, 한 번만)** 를 결제합니다.
3. 신분증으로 **본인 인증**을 합니다. 승인까지 며칠 걸릴 수 있습니다.

> ⚠️ 새로 만든 개인 계정은 바로 공개 출시가 안 됩니다.
> **테스터 12명 이상이 14일 동안 계속 설치해 둔 "비공개 테스트"** 를 먼저 거쳐야 정식 출시를 신청할 수 있어요.
> 가족·친구·반 친구들에게 미리 부탁해 두세요. (테스터는 구글 계정 이메일만 있으면 됩니다.)

## 2단계. 앱 파일 만들기 (약 10분, 설치할 프로그램 없음)
1. https://www.pwabuilder.com 에 접속합니다.
2. 주소 칸에 `https://yuna123-tech.github.io/sudoku/` 를 넣고 시작 버튼을 누릅니다.
3. **Package For Stores**(스토어용 패키지) → **Android** → **Generate Package** 를 누릅니다.
4. 설정 화면에서 다음만 확인하고 나머지는 그대로 둡니다.
   - **Package ID**(앱 고유 이름): `io.github.yuna123tech.sudoku`
   - **App name**(앱 이름): `스도쿠 놀이터`
   - **Launcher name**(아이콘 아래 이름): `스도쿠`
   - **Signing key**(서명 키): **New**(새로 만들기) — 이름·조직 칸은 본인 정보로 채웁니다.
5. **Download** 를 눌러 압축 파일을 받습니다. 안에 들어 있는 파일:
   - `.aab` 파일 → 플레이 스토어에 **올릴 파일**
   - `.apk` 파일 → 내 휴대전화에 직접 설치해 **미리 시험해 볼 파일**
   - `signing.keystore`, `signing-key-info.txt` → **앱 열쇠**
   - `assetlinks.json` → 3단계에서 사용

> 🔑 **앱 열쇠(`signing.keystore`와 비밀번호 파일)는 절대 잃어버리거나 공개하면 안 됩니다.**
> 잃어버리면 앱을 다시는 업데이트할 수 없어요. USB·클라우드 등 두 군데 이상에 따로 보관하세요.
> GitHub 저장소에는 올리지 마세요(공개 저장소라 누구나 볼 수 있습니다).

## 3단계. 주소창 없애기 (사이트 소유 증명)
이 단계를 건너뛰면 앱 위쪽에 인터넷 주소창이 보입니다.

1. GitHub에서 이름이 정확히 **`Yuna123-tech.github.io`** 인 새 저장소(공개)를 만들어 주세요.
2. 받은 `assetlinks.json` 파일의 **내용**을 저(Claude)에게 보내 주세요.
3. 플레이 콘솔에 앱을 만든 뒤 **테스트 및 출시 → 앱 무결성 → 앱 서명** 화면에 있는
   **"앱 서명 키 인증서"의 SHA-256 지문**도 함께 보내 주세요.
   (구글이 앱을 한 번 더 서명하기 때문에 두 지문이 모두 필요합니다.)
4. 그러면 제가 파일을 올려서 `https://yuna123-tech.github.io/.well-known/assetlinks.json` 주소에 연결해 드립니다.

※ `assetlinks.json` 안의 지문은 공개되어도 안전한 정보입니다. (열쇠 파일과 다릅니다.)

## 4단계. 플레이 콘솔에서 앱 등록
1. **앱 만들기** → 앱 이름 `스도쿠 놀이터`, 언어 **한국어**, **게임**, **무료** 선택
2. **스토어 등록정보**: `listing.md` 의 문구를 복사해 넣고, 아이콘·배너·스크린샷을 올립니다.
3. **앱 콘텐츠** 항목들을 채웁니다.
   - 개인정보처리방침: `https://yuna123-tech.github.io/sudoku/privacy.html`
   - 광고: **광고 없음**
   - 앱 액세스 권한: **모든 기능 이용 가능 (로그인 없음)**
   - 콘텐츠 등급 설문: 카테고리 **게임**, 폭력·선정성 등 모두 **아니요** → 보통 "전체 이용가"
   - 타겟층: 원하는 연령 선택 (어린이 포함 가능)
   - 데이터 보안: **사용자 데이터를 수집하거나 공유하지 않음**
4. **테스트 → 비공개 테스트**에 `.aab` 파일을 올리고, 테스터 이메일 12개 이상을 등록합니다.
5. 테스터들이 초대 링크로 설치 → **14일** 유지
6. 14일 후 **프로덕션(정식 출시) 신청** → 구글 검토(보통 며칠) → 출시 🎉

## 이후 업데이트
- 게임 내용 수정: 웹사이트(GitHub)만 고치면 앱에도 자동 반영됩니다.
- 앱 이름·아이콘을 바꿀 때만 PWABuilder로 새 파일을 만들어 다시 올립니다. (이때 **같은 앱 열쇠**를 써야 합니다.)

## 아이폰(앱 스토어)은?
연 99달러 개발자 등록과 **맥(Mac) 컴퓨터**가 필요하고, 웹사이트를 감싼 앱은 심사에서 거절될 수 있습니다.
지금은 Safari → 공유 → **홈 화면에 추가** 방식(무료, 오프라인 지원)을 추천합니다.
