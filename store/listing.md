# 스토어 등록정보 문구

## 앱 이름 (30자 이내)
```
스도쿠 놀이터 - 8가지 스도쿠
```

## 간단한 설명 (80자 이내)
```
클래식·킬러·지그소 등 8가지 스도쿠를 5단계 난이도로! 오프라인에서도 무료로 즐기세요.
```

## 자세한 설명 (4000자 이내)
```
매번 새로운 퍼즐! 8가지 종류와 5단계 난이도로 질리지 않는 스도쿠를 즐겨 보세요.

■ 8가지 스도쿠
· 클래식 – 가장 기본적인 스도쿠
· 대각선(X) – 두 대각선에도 1~9가 한 번씩
· 하이퍼(윈도쿠) – 색칠된 네 개의 창에도 1~9가 한 번씩
· 지그소 – 박스 대신 불규칙한 모양의 영역
· 킬러 – 점선 칸 안 숫자의 합을 맞추는 퍼즐
· 홀짝 – 네모 칸은 짝수, 동그라미 칸은 홀수
· 센터 도트 – 각 박스의 가운데 칸끼리도 1~9
· 아스테리스크 – 별 모양 9칸에도 1~9

■ 5단계 난이도
입문 · 쉬움 · 보통 · 어려움 · 전문가
모든 퍼즐은 정답이 딱 하나뿐이도록 만들어집니다.

■ 편리한 기능
· 메모(후보 숫자 적기)와 자동 메모
· 실행취소, 힌트, 오답 표시
· 같은 숫자·관련 칸 강조
· 실수 3번이면 게임 오버 (설정에서 끌 수 있어요)
· 날마다 바뀌는 "오늘의 퍼즐"
· 다크 모드

■ 기록과 랭킹
· 종류·난이도별 최고 기록
· 내 기록 순위(상위 10개)와 평균 시간
· 하던 게임은 자동 저장되어 언제든 이어하기

■ 안심하고 즐기세요
· 인터넷 없이도 플레이 가능
· 광고 없음, 회원가입 없음
· 개인정보를 수집하지 않습니다
```

- 카테고리: 퍼즐
- 태그 예시: 스도쿠, 퍼즐, 두뇌 게임, 숫자 게임
