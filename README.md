# 스도쿠 놀이터

8가지 종류 × 5단계 난이도의 스도쿠를 즐기는 웹앱입니다. 빌드 과정 없이 정적 파일만으로 동작하며 GitHub Pages로 배포됩니다.

## 스도쿠 종류
| 종류 | 규칙 |
| --- | --- |
| 클래식 | 행·열·3×3 박스에 1~9 |
| 대각선 (X) | + 두 대각선에도 1~9 |
| 하이퍼 (윈도쿠) | + 색칠된 4개의 3×3 창에도 1~9 |
| 지그소 | 박스 대신 불규칙한 9칸 영역 (매번 새로운 모양) |
| 킬러 | 점선 케이지의 합 일치, 케이지 내 중복 금지 |
| 홀짝 | 네모 칸은 짝수, 동그라미 칸은 홀수 |
| 센터 도트 | + 각 박스 가운데 칸 9개에도 1~9 |
| 아스테리스크 | + 별 모양 9칸에도 1~9 |

난이도: 입문 · 쉬움 · 보통 · 어려움 · 전문가. 모든 퍼즐은 무작위로 생성되며 **해답이 유일함**을 검증합니다. 입문·쉬움은 기본 기법(싱글)만으로 풀 수 있게 만들어집니다.

## 기능
- **실수 3번 제한**: 3번 틀리면 게임 오버 → 같은 퍼즐 다시하기 / 새 퍼즐 (설정에서 끌 수 있음)
- 메모(연필 표시), 자동 메모, 실행취소, 힌트, 오답 표시, 같은 숫자/관련 칸 강조
- 키보드 조작 (숫자, 방향키, `Shift+숫자` 메모, `Ctrl+Z`, `N`, `H`, `P`)
- 날짜별로 모두에게 같은 **오늘의 퍼즐**
- **내 랭킹**: 종류×난이도별 개인 기록 순위(상위 10개, 평균·최고 시간), 완료 시 "내 기록 중 N등" 표시
- **한국어 / English** 선택 (상단 🌐 버튼 또는 설정, 처음엔 브라우저 언어로 자동 선택)
- 라이트/다크 테마
- **한 화면 맞춤**: 휴대폰(세로·가로), 폴드, 태블릿, PC 어디서나 스크롤 없이 한 화면에 표시

## 저장 (플레이어 브라우저의 localStorage)
서버 없이 플레이어의 브라우저에 자동 저장됩니다.
- `sudoku:saves` — 진행 중인 게임 (종류·난이도별로 따로 저장, 입력·메모·시간·실행취소 기록 포함)
- `sudoku:records` — 완료 기록, 종류×난이도별 최고 기록, 오늘의 퍼즐 완료 기록
- `sudoku:settings` — 설정, 테마, 마지막 게임

기록 화면에서 JSON 파일로 **내보내기/가져오기**하여 다른 기기로 옮길 수 있습니다.

## 앱으로 설치 (PWA)
- **갤럭시(안드로이드)**: Chrome/삼성 인터넷에서 상단 `📲 앱 설치` 버튼 또는 메뉴 → *홈 화면에 추가 / 앱 설치*
- **아이폰**: Safari → 공유 버튼 → *홈 화면에 추가*
- 설치 후 전체 화면 앱처럼 실행되고, 서비스 워커(`sw.js`) 덕분에 오프라인에서도 플레이할 수 있습니다.

## 안드로이드 앱 (광고 포함)
- 같은 게임 파일을 앱 안에 넣은 Capacitor 앱입니다. 광고(구글 애드몹)는 **앱에만** 나오고 웹사이트에는 없습니다.
- `main`에 올리면 GitHub Actions가 앱 파일을 자동으로 만듭니다.
- 시험용 앱 받기: [Releases → android-latest](https://github.com/Yuna123-tech/sudoku/releases/tag/android-latest)
- 수정 방법·파일 구조는 [`CLAUDE.md`](CLAUDE.md) 참고

## 로컬 실행
```bash
python3 -m http.server 8000
```
→ http://localhost:8000

## GitHub Pages 배포
1. 이 폴더를 GitHub 저장소에 푸시합니다 (`main` 브랜치).
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. `main`에 푸시할 때마다 `.github/workflows/deploy.yml`이 자동 배포합니다. 주소: `https://<사용자명>.github.io/<저장소명>/`
